# PayQuant Changelog

## v1.0.0-alpha (2026-08-08)

### Initial Release Highlights
- **Post-Quantum Cryptography**: NIST FIPS 204 ML-DSA-65 (Dilithium) & SLH-DSA signature verification.
- **Synergeia Hybrid Consensus**: 15-second block target with 27 active validator rotation slots.
- **Proof of Useful Work (PoUW)**: Zero-Knowledge Machine Learning (ZKML) verification engine.
- **RinHash Algorithm**: Multi-stage ASIC-resistant hash pipeline (BLAKE3 + Argon2d + SHA3-256).
- **Vulkan GPU Miner**: Precompiled standalone miner (`vulkan_miner.exe`).
- **Spenden-Wallet**: Automated 50 PQN treasury distribution every 1,440 blocks.
- **FMARL AI Agent**: Dynamic block size & fee tuning.
- **Security Sentinel**: Qiskit 5-Qubit quantum entropy audit & 10,000 block warmup period.
- **Windows Packaging**: Precompiled `payquant-qt.exe`, `payquantd.exe`, `payquant-cli.exe`, `vulkan_miner.exe`, and Setup Installer (`payquant-1.0.0-win64-setup.exe`).
