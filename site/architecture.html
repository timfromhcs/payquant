System Architecture

The PayQuant ecosystem is a stack of zero-dependency engines that combine into a full node, miner, wallet and explorer.

Zero-Port NAT Traversal (5-Layer Cascade)

Nodes stay reachable behind home routers without port forwarding. Each layer falls back to the next until a route is established:

L1  WebRTC DataChannels (ICE + public STUN)
      └─ fallback → L2  IRC DCC SEND / RESUME / Reverse DCC
           └─ fallback → L3  STUN UDP Hole Punching
                └─ fallback → L4  Direct TCP
                     └─ fallback → L5  Encrypted IRC Base64 Relay

IRC signaling runs on #payquant-mainnet (Libera / OFTC) so peers discover each other without any central server or forwarded ports.

Enterprise Storage (RocksDB)

The contrib/chain_db.py engine stores the chain in tuned column families with an in-memory UTXO LRU cache, Bloom filters and automatic database repair on startup:

  • blocks — serialized block headers & transactions
  • utxo_set — spendable outputs with cached lookups
  • snapshots — fast-sync UTXO snapshots
python scripts/local_test_suite.py     # 13-category ecosystem test gate

Fast-Sync UTXO Snapshots

New nodes pull a verified UTXO snapshot (fast_sync_engine.py) instead of replaying every transaction, reducing initial sync from hours to minutes, then download only missing block ranges over the P2P transport.

RinHash Proof of Work

ASIC-resistant memory-hard PoW. The solo miner distributes jobs via WebSocket (get_mining_job / submit_block), credits 50 PQN per block and persists the payout address in miner_config.json.

Background Daemon Orchestration

The process manager (backend/daemon.py) launches node, miner, API and signaling as independent background processes with pidfiles, graceful shutdown and health checks:

python backend/daemon.py start all
python backend/daemon.py status
python backend/daemon.py stop all

# or via one-shot helpers
scripts/start_backend.bat   # Windows
scripts/start_backend.sh    # Linux / macOS
