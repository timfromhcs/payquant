🚀 Core Features

⚛️

Post-Quantum Cryptography

NIST FIPS 204 ML-DSA-65 (Dilithium) schützt Transaktionen gegen Quantencomputer-Angriffe. Fallback: SLH-DSA (SPHINCS+).

Public Key: ~1.312 Bytes | Signature: ~2.420 Bytes

⚡

Synergeia Consensus

Hybrid PoW + PoS mit 15-Sekunden-Block-Finalität und 27 dynamischen Validator-Slots. Super-exponentielle Sicherheit gegen 40%-Angreifer.

ε(k) ≤ exp(-C₁k²) + exp(-C₂k) | k = 26 für ε ≤ 10⁻⁹

🤖

PoUW + ZKML

Proof of Useful Work: GPU-Zyklen trainieren echte KI-Modelle. Zero-Knowledge-Proofs verifizieren die Korrektheit des Trainings.

Dezentralisierte KI-Entwicklung ohne zentrale Anbieter

⛏️

RinHash Mining

ASIC-resistenter PoW mit BLAKE3 + Argon2d + SHA3-256. Läuft auf jeder Vulkan-GPU – kein CUDA, kein ROCm, keine Treiber-Fiddling.

High-End GPU: ~3-5 GH/s

💰

Spenden-Wallet

Automatische 50 PQN-Ausschüttung alle 1.440 Blöcke (~6h) an alle aktiven Nutzer. Anti-Sybil-Schutz durch Aktivitäts-Hürde.

Nur Wallets mit Transaktion in letzten 1.440 Blöcken gelten als aktiv

🧠

FMARL AI Agent

Federated Multi-Agent Reinforcement Learning optimiert kontinuierlich Gebühren, Block-Größen und Peer-Routing.

98.67% Genauigkeit | 97.55% Präzision | 98.77% F1-Score

⚡ Quick Start

# Repository klonen
git clone https://github.com/timfromhcs/payquant.git ~/payquant
cd ~/payquant

# Kompilieren
mkdir build && cd build
cmake .. -DBUILD_GUI=ON
make -j$(nproc)

# Node starten
./src/payquantd -daemon
./src/payquant-cli getblockchaininfo
