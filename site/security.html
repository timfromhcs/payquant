🛡️ NIST FIPS 204 — Post-Quantum Ready

Post-Quantum Security Model

Every PayQuant wallet is protected against both classical and quantum attackers today.

🧬

ML-DSA-65 (Dilithium)

Addresses and transaction signatures use the NIST-standardized lattice scheme — resistant to Shor's algorithm and future quantum decryption (FIPS 204).

🔐

Argon2id Master Password

The seed is AES-256-GCM encrypted on disk with a memory-hard Argon2id-derived key. Readable only after unlocking with the master password.

📝

24-Word BIP-39 Seed

Full 2048-word standard wordlist with checksum validation. Recovery is seed-only — there is deliberately no password reset path.

Threat Prevention

  • Private keys never leave the device — signing happens locally in the wallet.
  • Seed never stored in plaintext — only the encrypted vault file and an Argon2id password hash are persisted.
  • Auto-lock after 10 minutes of inactivity; in-memory session is cleared on lock.
  • No password reset — recovery requires the 24-word seed, protecting against both attackers and social-engineering resets.

Recommended Backup Best Practices

  1. Write the 24 seed words on paper in exact order during wallet creation.
  2. Keep at least two physical copies in separate, secure locations.
  3. Never store the seed in cloud notes, emails or screenshots.
  4. Never enter the seed on any website or share it with anyone.
  5. Test a restore from the seed into a fresh PayQuant wallet before sending significant funds.

⚠️ Remember: whoever holds the 24-word seed controls the wallet. There is no master password reset — if the password is lost, the seed is the only recovery path.
