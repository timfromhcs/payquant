2. Node Setup & Backend Daemons

git clone https://github.com/timfromhcs/payquant.git
cd payquant

# One-shot backend orchestration (node, miner, API, signaling)
scripts/start_backend.sh        # Linux / macOS
scripts/start_backend.bat       # Windows

# or individual control
python backend/daemon.py start all
python backend/daemon.py status
python backend/daemon.py stop all

3. JSON-RPC API Reference

Runs on port 28332 with HTTP basic auth. Get/status endpoints also exposed by the unified API server on 28377.

MethodDescription
getblockchaininfoCurrent height, best hash, difficulty and chainstate metrics.
getnetworkinfoP2P status, peer connections and ML-DSA-65 security state.
getnewaddressGenerate a new post-quantum address (bech32 hrp pqn).
sendtoaddress <addr> <amount>Sign & broadcast an ML-DSA-65 transaction.
generatetoaddress <n> <addr>Mine n blocks targeting addr.

4. RinHash PoW Mining

ASIC-resistant memory-hard PoW. The GUI miner auto-loads your saved payout address from miner_config.json:

python contrib/miner_gui.py                 # GUI solo miner
python backend/daemon.py start miner        # headless daemon miner

# CLI flags (all GUI executables):
python contrib/miner_gui.py --help

5. Testing & Validation Gate

python scripts/local_test_suite.py          # 7-category ecosystem test
python contrib/build_local_executables.py    # rebuild standalone binaries
cd wallet && npm run build:web               # wallet web/Android bundle
