2. Node Setup & P2P Dynamic HTTP Auto-Sync

Nodes and miners fetch active P2P peers automatically from the dynamic HTTP seed pool on launch:

# Clone official repository
git clone https://github.com/timfromhcs/payquant.git ~/payquant
cd ~/payquant

# Start node with auto HTTP seed discovery
python contrib/mainnet_webui.py

3. JSON-RPC API Reference

PayQuant RPC interface runs on port 28332 (HTTP basic auth):

MethodDescription
getblockchaininfoReturns current height, best block hash, difficulty, and chainstate metrics.
getnetworkinfoReturns P2P port status, peer connections, and ML-DSA-65 security state.
getnewaddressGenerates a new ML-DSA-65 post-quantum address (bech32 hrp pqn).
sendtoaddress <address> <amount>Signs and broadcasts an ML-DSA-65 transaction.
generatetoaddress <nblocks> <address>Mines nblocks targeting address.

4. RinHash Vulkan GPU Mining

RinHash is an ASIC-resistant PoW algorithm combining BLAKE3, Argon2d (64KB, 2 passes), and SHA3-256:

python contrib/vulkan_miner.py --threads 4 --address <YOUR_ADDRESS>
