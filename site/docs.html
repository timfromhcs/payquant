PayQuant Technical Documentation

Welcome to the official developer and operator documentation for PayQuant (PQN)—the post-quantum, self-optimizing AI blockchain built upon Bitcoin Knots.

Installation Guide

PayQuant provides precompiled Windows packages, macOS binaries, Linux tarballs, and Docker images.

# Windows Setup Installer (Recommended)
run release_dist/payquant-1.0.0-win64-setup.exe

# Docker Deployment
docker pull payquant/payquant:latest
docker run -d -p 28333:28333 payquant/payquant

ML-DSA-65 Post-Quantum Signatures

PayQuant implements NIST FIPS 204 ML-DSA-65 (Dilithium) signatures. Every transaction output created on PayQuant is protected against quantum decryption (Shor's algorithm).

Public Key Size: 1,952 Bytes
Secret Key Size: 4,032 Bytes
Signature Size: 3,309 Bytes

RinHash GPU & CPU Mining

RinHash is a multi-stage ASIC-resistant hashing algorithm combining BLAKE3 pre-expansion, Argon2d memory-hard transformation, and SHA3-256 compression.

# Mine with precompiled Vulkan GPU Miner
vulkan_miner.exe --max-nonces 1000000

RPC API Commands

Use payquant-cli.exe to interact with running payquantd daemons:

payquant-cli getnetworkinfo
payquant-cli getblockchaininfo
payquant-cli getwalletinfo
payquant-cli getnewaddress
